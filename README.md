# 🔥 RadiatorPro — магазин в Telegram

Твой личный интернет-магазин отопительного оборудования прямо в Telegram. Покупатель листает каталог, кладёт радиаторы и полотенцесушители в корзину, оформляет заказ и платит — всё в чате с ботом. А ты управляешь всем этим из удобной веб-админки, даже не открывая код.

Бот умеет разговаривать на двух языках — и с покупателем, и с тобой в админке. Знает имя покупателя и обращается по имени. Умеет подбирать товар с помощью Claude, если человек не знает, что именно ему нужно. И да, он платёжеспособный — принимает оплату через ЮKassa.

## 🧰 Что понадобится

1. **Node.js 20+** — `node -v` покажет, что уже стоит. Нет — бери на [nodejs.org](https://nodejs.org).
2. **Токен бота от BotFather**:
   - Пиши [@BotFather](https://t.me/BotFather) в Telegram.
   - `/newbot` → имя → username.
   - Он выдаст токен вида `123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx` — сохрани его.
3. **Свой chat ID** — чтобы бот знал, кто тут хозяин:
   - Напиши боту что угодно.
   - Открой `https://api.telegram.org/bot<ТВОЙ_ТОКЕН>/getUpdates`, найди `"chat":{"id":...}` — это и есть `OWNER_CHAT_ID`.
4. **Аккаунт в ЮKassa** — чтобы принимать деньги:
   - Регистрируешься на [yookassa.ru](https://yookassa.ru), берёшь `shopId` и секретный ключ в личном кабинете.
5. **Ключ Anthropic API** — чтобы бот умел подбирать товары умом:
   - [console.anthropic.com](https://console.anthropic.com) → API Keys → новый ключ (показывается один раз, сразу сохрани).

## 🚀 Установка

```bash
npm install
```

Создай `.env` в корне проекта:

```env
BOT_TOKEN=токен_от_botfather
BOT_USERNAME=username_бота_без_@
OWNER_CHAT_ID=твой_chat_id
YOOKASSA_SHOP_ID=id_магазина_в_юкассе
YOOKASSA_SECRET_KEY=секретный_ключ_юкассы
ANTHROPIC_API_KEY=твой_ключ_anthropic
ADMIN_USER=логин_для_веб-админки
ADMIN_PASS=пароль_для_веб-админки
WEBHOOK_PORT=3001
# DB_PATH=/data/shop.db  # опционально, если деплоишь куда-то с постоянным диском
```

И в личном кабинете ЮKassa укажи адрес вебхука для `payment.succeeded`:
`https://<твой-домен>/yookassa-webhook`.

## ▶️ Запуск

```bash
npm start
```

Если в консоли всё зелёное и без ошибок — бот и вебхук-сервер запущены. Иди в Telegram, жми `/start`.

Локально бот живёт, пока открыт терминал. Для круглосуточной работы он задеплоен на [Railway](https://railway.app) — переменные окружения там задаются в настройках проекта, а `shop.db` лежит на подключённом Volume, чтобы не стираться при каждом деплое.

## 💬 Команды бота

| Команда | Что делает | Кому доступно |
| --- | --- | --- |
| `/start` | Здоровается; в первый раз спрашивает имя (и дальше зовёт по нему), во второй — сразу открывает меню | всем |
| `📦 Каталог` | Листаешь товары постранично | всем |
| `🛒 Корзина` | Смотришь корзину, идёшь оформлять | всем |
| `🤖 AI-подбор` | Описал, что нужно — Claude подобрал товар из каталога | всем |
| `📋 Мои заказы` | История заказов со статусами и коротким кодом | всем |
| «✅ Оформить заказ» | Город доставки → адрес → промокод → оплата ЮKassa | всем |
| `🌐 Язык / Language` | Переключить бот на русский или английский | всем |
| `/orders` | Список заказов | владельцу |
| `/addproduct Название \| Описание \| Цена \| Остаток \| Категория` | Добавить товар | владельцу |
| `/stock <id> <остаток>` | Поправить остаток | владельцу |
| `/markshipped <id_заказа>` | Отметить заказ отправленным (покупатель получит уведомление) | владельцу |
| `/adddelivery Город Цена` | Добавить/обновить тариф доставки | владельцу |
| `/deliveries` | Список тарифов доставки | владельцу |
| `/deldelivery Город` | Выключить тариф для города | владельцу |

Кстати, про имя и номер заказа — это две разные фишки. Имя бот спрашивает один раз, при первом `/start`, и дальше вставляет его в приветствие, в итог заказа и в уведомления об оплате/отправке. А номер заказа, который видит покупатель, — это не сквозной счётчик вроде «заказ №247» (по нему легко прикинуть, сколько у тебя вообще продаж), а короткий код из 4 символов, например `7K9M`. Внутри базы у заказа, конечно, остаётся и обычный ID — он нужен тебе для управления в админке.

## 🖥 Веб-админка

Живёт на `https://<твой-домен>/admin` (логин/пароль — `ADMIN_USER`/`ADMIN_PASS` из `.env`). Справа вверху переключатель `RU`/`EN` — меняет язык всей админки, запоминает выбор в браузере. Пять вкладок:

- **Товары** — добавляешь, редактируешь, грузишь фото (с компьютера или по ссылке), следишь за остатками. У каждого товара можно вписать английские название/описание/категорию (кнопка «🌐 EN») — если не вписать, англоязычный покупатель просто увидит русское название.
- **Заказы** — фильтр по статусу, поиск по номеру, коду, адресу или chat ID, клик по строке открывает карточку заказа целиком, смена статуса в один клик, выгрузка в CSV.
- **Промокоды** — создаёшь коды со скидкой, включаешь и выключаешь.
- **Доставка** — тарифы по городам, цена правится прямо в таблице, для всех остальных городов действует тариф по умолчанию. У городов тоже можно задать английское название.
- **Аналитика** — сколько заработала сегодня/за неделю/за месяц, средний чек, топ товаров.

## 🧩 Как это устроено

- `bot.js` — сердце бота: команды, кнопки, сцены, AI-подбор, знакомство с покупателем по имени.
- `db.js` — SQLite (better-sqlite3): схема таблиц, аккуратные миграции, тестовые данные. Тут же живут `getLang`/`setLang`, `getName`/`setName`, `generateOrderCode`, `getCityEn`/`translateCity` — весь двуязычный и «именной» багаж.
- `cart.js` — корзина.
- `notify.js` — шепчет тебе на ухо, когда что-то заканчивается на складе.
- `webhook.js` — Express-сервер: слушает ЮKassa, отдаёт API для админки, саму админку и загруженные фото.
- `middleware/isOwner.js` — фейс-контроль для владельческих команд.
- `payments/yookassa.js` — создание и проверка платежей.
- `scenes/checkout.js` — весь путь оформления заказа: город → адрес → промокод → оплата, плюс генерация кода заказа и приветствие по имени.
- `i18n.js` — все тексты бота на русском и английском в одном месте.
- `admin-public/index.html` — вся админка одним файлом, без сборки, со своим набором двуязычных строк и переключателем языка в шапке.
